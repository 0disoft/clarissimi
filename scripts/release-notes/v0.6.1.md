# Clarissimi {{VERSION}}

Clarissimi {{VERSION}} improves malformed-ledger diagnostics and makes the executable TypeScript
configuration trust boundary explicit without changing Action inputs, permissions, or defaults.

## Improved

- invalid JSONL now reports the one-based physical line number, including files with blank lines or
  CRLF line endings
- Action and consumer documentation now identify `clarissimi.config.ts` as executable runner code
  that must come from a trusted checkout
- release-readiness regressions preserve the TypeScript configuration warning across public docs

Existing gate, dry-run, propose, commit, stage-draft, and promote-draft behavior remains compatible.
The standalone npm CLI ships the same diagnostic fix as `clarissimi@0.1.2`; npm and Action versions
remain independent.
