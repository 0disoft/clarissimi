# Clarissimi {{VERSION}}

Clarissimi {{VERSION}} ships the accumulated correctness and security fixes from the current
`v0` development line while preserving existing Action inputs, permissions, defaults, and
maintainer approval boundaries.

## Fixed

- proposal commits are created from an isolated release branch so unrelated checkout history
  cannot leak into a recognition pull request
- approved contributor records retain deterministic identity and must satisfy the canonical
  ledger contract before derived output is written
- concurrent draft writes use race-safe creation and replacement semantics
- provider-result diagnostics redact structured and embedded secret-bearing values more
  consistently
- historic v1 ledger timestamps using valid UTC seconds are normalized to canonical millisecond
  form during rebuilds without accepting impossible dates

## Improved

- Action path security and configuration resolution are isolated behind focused modules with the
  same public behavior
- the tracked Action bundle includes the current fixes and remains installation-free for consumers
- cross-platform toolchain smoke now covers Ubuntu, macOS, and Windows development commands

The standalone npm CLI remains independently versioned at `clarissimi@0.1.2`; its unreleased
`render-page` command is not implied by this Action release.
