# Clarissimi {{VERSION}}

Clarissimi {{VERSION}} publishes the reviewed-draft and public-evidence safeguards added since
`v0.6.2`. Existing Action inputs, defaults, permissions, and readable v1 ledgers remain compatible.

## Improved

- approved drafts are bound to a content digest; editing an approved draft requires another review
- required pre-merge decisions verify the comment author's current repository write permission
- public claims in provider-generated drafts link to specific sanitized evidence references
- security, regression, and measured-performance claims require relevant linked evidence
- the tracked Action bundle contains the current implementation without consumer-time installation

## Fixed

- rebuilds no longer overwrite the canonical contribution ledger or lose concurrent imports
- public output rejects secret-bearing text and URLs before writing repository files
- repository identity and linked issue references retain their full source identity
- proposal reruns update their existing pull request without force-pushing unrelated history

The standalone npm CLI has an independent version and publication process. This Action release
does not publish a CLI package.
