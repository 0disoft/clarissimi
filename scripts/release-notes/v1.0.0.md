# Clarissimi {{VERSION}}

Clarissimi {{VERSION}} is the first stable root Action release. It keeps the reviewed-draft,
public-output, reviewer-permission, and claim-to-evidence safeguards published in `v0.7.0` and adds
the accumulated correctness, diagnostics, and usability fixes landed since. Existing Action inputs,
permissions, defaults, modes, and readable v1 ledgers remain compatible; ADR 0055 defines the stable
Action boundary, and ADR 0062 keeps the standalone CLI `1.x` contract compatible.

## Improved

- proposal generation is pinned to the checked-out base, so unrelated checkout history cannot leak
  into a recognition pull request
- reviewed proposal branches are preserved on reruns, and a failed rewrite keeps the existing
  proposal commit instead of replacing reviewed work
- input and output collisions are rejected before writing: overlapping Action summary, config, and
  ledger destinations fail closed instead of overwriting config or the canonical ledger
- atomic replacement preserves destination access permissions and cleans partial staging files
- CLI validation errors identify the configuration file, field, and JSON syntax location, and each
  command shows focused help
- PowerShell completion resolves option values and selectors at the cursor
- all linked contribution evidence is rendered, and linked GitHub issue URLs keep their full source
  identity

## Fixed

- provider HTTP errors and response-size failures survive stream cleanup instead of being masked
- recognition context and fixture evidence are validated before provider calls
- provider assessment hints are validated and redacted
- GitHub 403 rate limits are classified as retryable, and ineligible or disabled evidence requests
  are skipped
- conventional Go and Python test files and benchmark files are recognized as evidence
- a leading UTF-8 BOM is accepted, and impossible legacy ledger dates fail without a runtime error
- analytics windows are validated before reading the ledger, and undated records are explained
- the tracked Action bundle carries the current implementation without consumer-time installation

The standalone npm CLI has an independent version. The `clarissimi@1.0.0` candidate is prepared and
authorized under ADR 0062; it ships through the ADR 0056 staged-publication and maintainer-approval
gates, and this Action release does not publish it.
