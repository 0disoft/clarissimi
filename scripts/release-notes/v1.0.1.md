# Clarissimi {{VERSION}}

Compatible security, reliability, and performance fixes for the root GitHub Action.

## Fixed

- redact fine-grained GitHub credentials, quoted JSON credential keys, and equivalent sensitive key spellings
- sanitize Action JSON parse failures before diagnostics can expose source content
- bound private-key and email redaction scans to avoid quadratic work on adversarial input
- compare file identities with exact 64-bit values so distinct files cannot collide through number rounding
- restore earlier CLI outputs when a later generated file cannot be replaced
- avoid ledger reads whose results would be discarded by the requested CLI command

## Validation

- the installed standalone CLI verifier exercises draft staging, approval, import, and rebuild
- development dependencies refreshed within the selected compatible release lines
- existing Action inputs, outputs, permissions, defaults, CLI contracts, and ledger schemas remain unchanged

The independently versioned npm CLI `clarissimi@1.0.1` carries these fixes through the existing
staged-publication and maintainer-approval process. This Action release does not itself publish npm.
