# Clarissimi {{VERSION}}

Collect real merged pull requests and review an exact batch before recording recognition.
This compatible 1.x release also hardens redaction and Git publication boundaries.

## Added

- live merged-PR collection with bounded evidence coverage and dry-run or draft staging
- hash-bound review manifests and batch approval with one derived-output rebuild
- reviewer and linked-issue reporter candidates for explicit maintainer review

## Fixed

- redact evidence before truncation and mask complete authorization, cookie, URL credential,
  escaped assignment, and private-key values
- require measured evidence and consistent change direction for numeric performance claims
- bound assessment nesting and reuse parsed measurements and indexed evidence ranges
- verify generated blobs, immutable commit identity, remote base, and ownership across every
  unpublished commit before publishing Git changes
- keep upstream GitHub error bodies out of public diagnostics
- isolate multiline GitHub Action output values so they cannot introduce additional commands

Existing public Action and CLI contracts, permissions, defaults, and readable schemas remain
compatible. The independently versioned npm CLI `clarissimi@1.1.0` retains staged OIDC publication
and maintainer two-factor approval.
